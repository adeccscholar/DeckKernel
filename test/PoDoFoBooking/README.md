# PoDoFoBooking

Standalone C++23 PoDoFo 1.1.1 test project, using manually installed libraries.

- `main.cpp`: local PDF inspection and guarded CSV export.
- `pdf_booking.h/.cpp`: layout grouping and cents-exact conservative parser.
- `parser_test.cpp`: synthetic multi-page fixture without customer data.
- `CMakeLists.txt`: standalone CMake package discovery.

Full setup, privacy guidance and example commands:
[Docs/build/PODOFO_BOOKING.md](../../Docs/build/PODOFO_BOOKING.md).
