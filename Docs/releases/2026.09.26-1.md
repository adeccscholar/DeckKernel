## Integrity and installation

The canonical `Cache/StackPackages.xml` has SHA-256 `57280833634e4b7a026beafb2db430ff41774fe5c5e9722e9124866ca61ae447`.
Each published ZIP has a verified actual byte size and SHA-256 in
`Cache/thirdparty.lock` and `Cache/thirdparty.lock.xml`.
The existing CMake bootstrap verifies and installs missing/changed versioned
packages. These packages are intended for the native BCC64X dynamic DLL stack.
